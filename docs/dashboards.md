# Dashboards

## Student

Shows the learner's mastery bucket per skill plus a recent rating trend (last N
answers). Drives the practice loop: answer -> engine update -> next question.

## Teacher

Shows the class roster with each learner's per-skill mastery, the class-level
mastery distribution per skill, and which skills the class is weakest on. The
weakest-skill attribution and per-question drill-down are expanded in v4.
